# FAQ

This page will contain some common questions you might have!

# Will the latest version of the client work on the old V1 server?

It sure will! However ther are some things to consider:

* The V1 server will not support multiplayer functionality
* Eventually it may stop working with newer clients.

We're in the process of re-doing the godotGem protocol all together, as part of bringing in linux server support. There will be a phase where the client will support *both* V1 and V2 protocols, but eventually it will be taken out.

# Where can I download the server?

* [Get it over here! (Check the "Assets" section)](https://github.com/iSlammedMyKindle/godotGem/releases/latest)
* [Instructions to set it up are over here](../readme.md)

Note that the V2 server is in *beta*, I haven't worked with bridge mode in this version and it's **untested**. It's the only thing I haven't changed yet.

# The server won't launch!

Looks like you might need to have .NET installed:

* For V1 Users, [Grab .NET v7](https://dotnet.microsoft.com/en-us/download/dotnet/7.0)
* For V2 [Beta] Users, [Grab .NET v10](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)

# I'm having trouble connecting!

You'll wanna make sure that you know your *local* IP for connecting to your computer, [Check the directions for figuring it out!](../readme.md#how-to-start-godotgem)
